# NammaSkill
Android Studio project for NammaSkill app using Firebase Authentication and Firestore with real-time seat counts, registration, login, and application submission features.
# NammaSkill - Android Studio Project

## Features
- Firebase Authentication
- Firestore Database
- Real-time seat counts
- User registration & login
- Application submission
- Interest form submission
- Android WebView integration

## Tech Stack
- Android Studio
- Java
- Firebase Auth
- Firebase Firestore
- WebView

## How to Run
1. Open Android Studio
2. Click Open
3. Select `NammaSkill-Firebase`
4. Wait for Gradle sync
5. Connect Android device or emulator
6. Click Run ▶
